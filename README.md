## 我如何做 AI 产品

**发现问题 → 设计流程 → 验证能力 → 做出产品 → 评估迭代**

- **需求与体验**：拆解高频任务，明确用户需要的结果与交互路径。
- **模型与系统**：围绕 RAG、多模态、语音与工作流，权衡效果、延迟、成本和能力边界。
- **交付与验证**：用原型、代码和演示推进落地，让失败可解释、结果可纠正、效果可评估。

欢迎交流 AI 产品、内容工具与从零到一的实践。
